**Crash (`launches_on_device`)**
- **Cause:** in `src/ui/TutorialHand.tsx`, the tutorial hand's animation called a small `ease()` helper that wasn't marked as a worklet. React Native Reanimated then had to call back into JavaScript from the UI thread, which crashed the app.
- **Fix:** `ease()` is now marked `"worklet"`.
- I scanned every other animation in `src/` for the same pattern and found no other cases.
